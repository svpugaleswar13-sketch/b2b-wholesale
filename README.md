# Lotswap

A buyer-to-buyer wholesale marketplace demo built with plain HTML, CSS and JavaScript.

## Host on GitHub Pages
1. Create a new repository on GitHub and upload `index.html`, `style.css` and `script.js` to the root.
2. Go to Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` in a minute or two.

Note: listings are sample data held in memory and reset on reload.
